# User Profile Card Generator

## Overview

User Profile Card Generator is a simple web application that allows users to create and display a profile card by entering their personal information. The application collects user details through a form and dynamically generates a professional-looking profile card.

## Features

* Enter user name
* Enter user bio
* Add profile image URL
* Generate profile card instantly
* Responsive and modern user interface
* Simple and easy-to-use design

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Structure

UserProfileGenerator/

├── index.html

├── style.css

└── script.js

## How It Works

1. The user enters their name.
2. The user enters a short bio.
3. The user provides an image URL.
4. When the "Generate Profile" button is clicked, JavaScript reads the input values.
5. The profile card is updated dynamically and displayed on the screen.
